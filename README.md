# Watchfolio

O Watchfolio será um substituto pessoal do TV Time para acompanhar filmes, séries e animes pelo navegador do celular e do computador. A biblioteca começa vazia. O progresso, as avaliações e o histórico registrados daqui em diante deverão acompanhar o usuário entre aparelhos.

## Estado do projeto

Em 26 de novembro de 2026, a entrega é a documentação de escopo e planejamento. Todas as funcionalidades estão pendentes. Sites é a plataforma pretendida para publicação. O projeto ainda não tem código de aplicação, Site identificado, banco provisionado ou integração de catálogo verificada. O repositório escolhido é [ASCCJR/watchfolio no GitHub](https://github.com/ASCCJR/watchfolio).
